#  Aim Training

**Aim Training** is a first-person shooter game designed to enhance players' target accuracy and reaction speed through dynamic and progressively challenging environments.  
Developed in **Unreal Engine** using a combination of **C++** and **Blueprints**, this project focuses on precision shooting mechanics, fluid gameplay, and immersive level design.

---

##  Overview

The game challenges players to improve their aim and timing in a responsive virtual setting.  
Each level introduces new movement patterns, obstacles, and targets, encouraging continuous skill development.

### Key Features
-  **Precision Shooting System** – Built with C++ and Blueprints for responsive aim mechanics.  
-  **Progressive Difficulty** – Levels scale in complexity to match player improvement.  
-  **Dynamic Environments** – Varied level designs and target behaviors for realistic training scenarios.  
-  **Intuitive Controls** – Smooth player movement and aiming experience for both beginners and advanced players.
